# Zvuky pian

Každá složka má 30 vzorků (každý třetí půltón A0–C8, název souboru = číslo MIDI noty).
Tóny mezi nimi přehrávač dopočítá posunem výšky (nejvýš o půltón a půl).

| složka | zvuk | zdroj | licence |
|---|---|---|---|
| `salamander` | koncertní křídlo Yamaha C5 (výchozí) | [Salamander Grand Piano](https://archive.org/details/SalamanderGrandPianoV3), Alexander Holm, přes [tonejs.github.io](https://tonejs.github.io/audio/salamander/) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| `musyng` | klavír | Musyng Kite soundfont, přes [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) | [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) |
| `fatboy` | pianino | FatBoy soundfont ([fatboy.site](https://fatboy.site)), přes midi-js-soundfonts | [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) |
| `bright` | jasné piano | FluidR3_GM soundfont (Frank Wen), přes midi-js-soundfonts | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/us/) |
| `rhodes` | elektrické piano (Rhodes) | FluidR3_GM, přes midi-js-soundfonts | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/us/) |
| `honkytonk` | honky-tonk (rozladěné pianino) | FluidR3_GM, přes midi-js-soundfonts | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/us/) |

Vzorky jsou beze změn (jen výběr not). Vzorky pod CC BY-SA se šíří pod stejnou licencí.
